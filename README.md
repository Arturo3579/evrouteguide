# EV Route Guide

Practical guides, cost calculators and honest reviews for electric vehicle owners in the United States.

## Stack

- **Framework:** Astro 6.x (static build)
- **Styling:** Custom CSS with dark/light theme toggle
- **Deployment:** Vercel
- **Domain:** https://www.evrouteguide.com

## Pages

- **Home** — EV vs Gas cost calculator + featured content
- **Guides** — Curated EV ownership guides
- **Calculator** — Detailed cost comparison tool
- **About** — Site mission and methodology
- **Legal** — Privacy, Terms, Cookie Policy

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Static output is generated to `dist/`.
